Workflow

Start every file
rfc or rafce → Tab through placeholders
rfc = default fn  ·  rafce = arrow fn
Building out the component
us for state  ·  uem to fetch on mount
nform + hsubmit for a controlled form
maplist to render a list  ·  er-empty right after
er-load and er-error before the main return
Adding types
Switch to rafcep or rfcp to add a Props interface
CRUD -- client fetch
apiget inside uem to load data on mount
apipost inside hsubmit to create a record
apiput on edit  ·  apidel on delete
apiurl at top of file to define base URL once
CRUD -- Server Actions
nsaget in async Server Components to read data
nsapost nsaput nsadel for mutations
Debugging
cl quick log  ·  ct for arrays  ·  clj for objects
cwarn above anything tricky  ·  cquest when unsure
